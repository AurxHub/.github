## 🏢 Que es Cinkit?

**Cinkit** es un Estudio de Arquitectura de Software. Transformamos ideas abstractas en activos digitales solidos: automatizacion con IA, aplicaciones a medida y productos propios.

No construimos webs. **Construimos activos.**

Operamos en dos lineas:

- **Servicios** — Desarrollo a medida, automatizacion inteligente y consultoria para empresas
- **Productos** — Una suite de aplicaciones propias de bienestar y gestion personal
